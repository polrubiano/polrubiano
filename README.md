### 🏆 Featured work

**[Eye Sense](https://github.com/polrubiano/eyesense)**: eye-tracking communication system for people with reduced mobility, a team project developed with my classmates as our DAM final project. Winner of the *Castilla y León Research and Innovation Award 2025-26* (best Vocational Training research project). I designed its hexagonal keyboard and built the tool that validates it.<br />The app's code is private; the repo is a public overview.

**[Letter Metter](https://github.com/polrubiano/letter-metter)**: Python CLI and library that measures eye travel on a keyboard layout. It found the Eye Sense layout needs **53% less eye travel than QWERTY** on the full text of *Don Quijote*. Tested with pytest, linted with ruff, CI on Linux and Windows.
